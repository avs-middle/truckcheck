# TruckCheck · ชุดไฟล์ขึ้นเว็บ

โฟลเดอร์นี้คือแอปตรวจรถจับไก่ทั้งแอป เป็นไฟล์ static ล้วน ไม่มีเซิร์ฟเวอร์และไม่มีฐานข้อมูล
ข้อมูลการตรวจอยู่ในมือถือแต่ละเครื่อง จนกว่าผู้ตรวจจะกด "ส่งผล" เป็นอีเมลเข้า Gmail กลาง

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | หน้าแรก: เลือก "บันทึกข้อมูลรถจับไก่" หรือ "ดูสรุปผล" (ใส่รหัส) + หน้ากราฟสรุปผล + ส่งออก Excel / CSV สำหรับ Power BI |
| record.html | แอปบันทึกตรวจรถ 3D (ใครมีลิงก์ก็ใช้ได้) |
| manifest.webmanifest + icons/ | ให้ติดตั้งลงหน้าจอมือถือได้ (ชื่อ TruckCheck) |
| sw.js | เก็บแอปไว้ในเครื่อง เปิดได้แม้ไม่มีสัญญาณ |
| .nojekyll | สำหรับ GitHub Pages |

## หน้าดูสรุปผล
- ใส่ PIN ก่อนดู (PIN ตั้งไว้ใน Apps Script และตรวจที่สคริปต์ ไม่อยู่ในหน้าเว็บนี้) กดผิดหลายครั้งระบบล็อก 15 นาที
- ข้อมูลมาจาก Microsoft List TruckInspections: Flow "TruckCheck-Snapshot" ส่งข้อมูลทั้ง List ทุก 30 นาที → Apps Script เก็บไว้ → หน้านี้ดึงไปทำกราฟ
  แก้หรือลบแถวใน List แล้ว กราฟเปลี่ยนตามในรอบถัดไป · อีเมลที่ Flow ส่งมาเป็นแค่ตัวขนส่ง สคริปต์ลบทิ้งเอง
- ไม่มีเน็ต: แสดงข้อมูลชุดล่าสุดที่เคยโหลด · ถ้า List ไม่ส่งข้อมูลมาเกิน 26 ชั่วโมง หน้าจะเตือนให้ตรวจ Flow
- ปุ่มส่งออก: Excel (Summary / Inspections / Checkpoints) หรือ CSV สองตาราง เชื่อมกันด้วย InspectionID ใน Power BI
- ทุกเช้า 07:00 Apps Script ส่งอีเมลสรุปผลของเมื่อวานเข้า Gmail กลาง ป้าย TruckCheck-Summary

## อัปเดต Apps Script (เมื่อได้ไฟล์ .gs ใหม่จากผู้ดูแล)
โค้ด Apps Script ไม่อยู่ใน repo นี้ เพราะมี PIN และอีเมลกลาง
1. วางโค้ดใหม่ทับทั้งหมด → บันทึก → เลือกฟังก์ชัน `setup` → Run (อนุญาตสิทธิ์)
2. Deploy → Manage deployments → ✏️ Edit → Version: **New version** → Deploy (ลิงก์ /exec เดิมใช้ต่อได้)

## วิธีที่ 1: GitHub Pages (ฟรี เร็วที่สุด)
1. สร้าง repository ใหม่ใน GitHub เช่น `truckcheck` (Public สำหรับบัญชีฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก repository (Add file → Upload files)
3. Settings → Pages → Source = Deploy from a branch → Branch = main, / (root) → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/truckcheck/`

หมายเหตุ: repository แบบ Public ใครก็เปิดดูโค้ดและเปิดแอปได้ แต่ไม่มีข้อมูลการตรวจอยู่บนเว็บ

## วิธีที่ 2: Azure Static Web Apps (ถ้า IT ให้ใช้)
ส่งโฟลเดอร์นี้ให้ IT แล้วแจ้งว่าเป็น static site, app location = `/`, ไม่มี build step

## ลิงก์สำหรับแจกผู้ตรวจ
ใส่อีเมล Gmail กลางต่อท้ายลิงก์ ผู้ตรวจไม่ต้องพิมพ์เอง:

`https://<ที่อยู่เว็บ>/?k=<อีเมลเข้ารหัส base64url>` (หรือ `?to=อีเมล` แบบไม่เข้ารหัส) ระบบอ่านแล้วลบออกจากแถบที่อยู่ทันที

เปิดลิงก์ครั้งแรกแล้ว ระบบจำอีเมลไว้ในเครื่อง จากนั้นให้ติดตั้งลงหน้าจอ:
- Android (Chrome): เมนู ⋮ → เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป
- iPhone (Safari): ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

## เวลาอัปเดตแอป
แก้ index.html / record.html แล้วเปลี่ยน `VERSION` ใน sw.js เป็นเลขใหม่ (เช่น truckcheck-v2) ก่อนอัปโหลด
มือถือจะได้แอปใหม่เมื่อเปิดแอปตอนมีสัญญาณ (อาจต้องเปิด 2 ครั้ง)
